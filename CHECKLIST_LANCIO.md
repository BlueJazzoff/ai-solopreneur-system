# Checklist operativa — AI Solopreneur System

## Da fare prima di vendere
- [ ] Decidere: Whop App integrata oppure sito esterno collegato da Whop.
- [ ] Creare prodotto e piani/prezzi in Whop.
- [ ] Configurare hosting e URL di test.
- [ ] Inserire API key solo come secret nel provider hosting.
- [ ] Implementare autenticazione e controllo entitlement lato server.
- [ ] Definire limiti per ogni livello e un tetto di spesa API.
- [ ] Verificare che utenti non autorizzati non possano chiamare `/api/chat`.
- [ ] Aggiungere database per cronologia solo dopo aver definito privacy e conservazione.
- [ ] Pubblicare privacy policy, termini e contatto supporto.
- [ ] Testare acquisto, accesso, cancellazione, rimborso e scadenza abbonamento.
- [ ] Fare test da telefono e desktop.
- [ ] Solo dopo, aggiungere il collegamento pubblico dalla pagina Whop.

## Credenziali e dati
Non condividere mai password, codici 2FA o API key in chat. Inseriscili direttamente nelle impostazioni ufficiali dei servizi. Per un'integrazione guidata, condividi soltanto screenshot non sensibili delle schermate di configurazione.
